1. Click the server.py and make sure the 192.x.x.x code matches the one referred in the code of App.js in folder of YojnaConnect
2. Open the YojnaConnect folder and in address bar press cmd to open command prompt
3. Type npx expo start there to start the expo server and scan the qr from your expo go app on phone to open the app
4. Now, the frontend of the app is ready to be demonstrated as long as the expo server is runnning
5. To enable backend so that the app can handle the chat sent by user and reply accordingly we need to run node server.js to initialize the backend code (server.js)
